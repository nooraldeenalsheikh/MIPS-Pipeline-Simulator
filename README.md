# MIPS Pipeline Simulator

A C++ simulator for MIPS pipelining that supports multiple execution modes including instruction reordering, hazard handling, and performance analysis.

## Features
- MIPS instruction simulation
- Pipeline execution
- Instruction reordering
- Hazard detection and handling
- Pipeline performance analysis
- Multiple execution modes

## Technologies Used
- C++
- Visual Studio

## Project Modes
The simulator supports:
- Normal execution
- Pipelining only
- Reordering only
- Reordering with pipelining

## Files
- `main.cpp` → Program entry point
- `Simulator.cpp` → Core simulation logic
- `Reorder.cpp` → Instruction reordering
- `Hazards.h` → Hazard handling
- `Speedup.cpp` → Performance calculations
